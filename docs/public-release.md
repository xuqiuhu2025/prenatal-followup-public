# 公开版本说明

本仓库是随访系统源码的独立发布版本，使用新的 Git 历史。只包含应用代码、迁移脚本、配置模板、测试、通用文档和虚构示例。

公开前处理：

- 移除真实服务器域名、公网和私网地址、云环境标识及私人运维记录。
- 电话部署入口改为显式读取部署者自己的环境变量。
- 排除实际服务验收脚本、配置二维码、凭据、患者数据、通话报告和录音。
- 保留第三方库许可证与通用合成语音样本；重新构造导入演示数据。
- 不继承旧的部署与备份历史。

日常开发请在自己的仓库配置忽略规则并审查暂存内容。新增 .gitignore 不会删除已经进入 Git 历史的敏感内容。公开源码并不提供正在运行的医院服务访问权。

本仓库目前尚未选择整体开源许可证；第三方组件按各自许可证使用。

## 本次发布验证

2026-11-20 在 Windows / Node.js 24 环境完成 95 项单元与本地模拟测试，92 个 JavaScript 文件及 4 个 Python 文件通过语法检查，15 条虚构导入记录通过格式和禁止拨号校验。电话部署脚本缺少必要配置时在调用 Docker 前停止。

这些验证不连接实际患者或运营商线路，也不代表任意部署环境的真实通话验收。
