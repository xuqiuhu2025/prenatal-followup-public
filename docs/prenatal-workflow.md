# 筛查与诊断一体化中心随访

本次调整以国家卫生健康委《产前筛查和产前诊断质量控制指标》（2023 年）为参考：
https://www.nhc.gov.cn/fys/c100078/202312/365527cd4c614965a81a231e46be94ae/files/1733998339155_78179.pdf

页面“项目与规范”包含原文入口。系统用于随访登记与管理，报告判读、咨询、诊断适应证和处理方案由有资质的医护确认；业务计数不等同于正式质控报表。

## 数据与工作流程

病案号对应孕妇基础档案，“病案号 + 孕次编号”对应一次妊娠。同一孕妇再次妊娠须另建孕次；同一孕次可纳入多个项目，胎数支持 1–6。已有逐胎临床记录后不能直接修改胎数。

| 项目 | 主要登记内容 | 可用随访节点 |
| --- | --- | --- |
| 血清学产前筛查 | 筛查方法、目标疾病、检查孕周、报告风险 | 结果告知与咨询、转诊/诊断落实、妊娠结局、出生后随访 |
| 无创产前筛查（cffDNA/NIPT） | 同上，按报告注明 T21/T18/T13 等目标 | 同上 |
| 超声产前筛查 | NT/结构筛查等方法、可疑异常 | 告知与咨询、转诊/诊断落实、妊娠结局、出生后随访 |
| 遗传学产前诊断 | 诊断指征、核型/CMA/分子遗传等方法、诊断结论、取材日期与方式 | 转诊/诊断落实、介入术后一周、报告与遗传咨询、结局、出生后随访 |
| 超声产前诊断 | 方法、诊断结论、异常描述 | 转诊/诊断落实、报告与咨询、结局、出生后随访 |

所有项目另有个体化补充节点。筛查风险与诊断结论分别保存；不自动将高风险改成确诊。

计划由医护勾选节点并确认日期、责任人和随访方式。术后节点建议实际介入日期 +7 天；妊娠结局可先以预产期暂排；出生后节点建议实际出生日期 +84 天。所有待办均可调整日期与责任人，须记录原因。实际事件日期与实际随访日期另行保存，不把计划日期当成实际发生日期。

## 联系结果与逐胎资料

- 告知/咨询节点：是否告知、咨询落实、实际咨询日期和机构/医师。
- 转诊节点：安排、到诊及诊断落实、机构和实际日期。拒绝咨询/诊断如实保留，不记为完成咨询/诊断。
- 介入术后节点：未报告异常、报告不适或胎儿丢失、事件日期与说明。不由系统判断因果。
- 妊娠结局：按胎儿序号登记活产、死胎/死产、自然流产、终止妊娠或未知/继续妊娠，保存日期、出生缺陷、体重及依据。
- 出生后随访：按胎儿序号登记活产儿实际出生日期、儿童健康及目标疾病核实；非活产胎儿保留结局说明。核对本孕次结局与出生日期，适用于多胎结局不同的情况。

信息来源区分孕妇/家属自述、病历或正式报告、医疗机构反馈与未核实。目标疾病确诊/排除须有病历/报告或机构依据及说明。未落实或未知结果按节点要求安排再次随访。

未接通保留待办并重约；拒绝本次随访或取消节点结束该节点，不代表孕次完成。孕次另设“随访中、已结案、失访、拒绝继续随访”，变更需要原因并保留记录。非活跃孕次不可新建计划；重新开启后可补充资料。

## 结案检查与参考指标

国家指标要求分别关注血清学/cffDNA 高风险告知咨询与结局随访、介入术后一周内胎儿丢失，以及遗传学/超声诊断随访。高风险筛查随访至少至分娩后12周，包含出生缺陷和儿童疾病情况。

系统结案检查：全部待办已处理、逐胎妊娠结局和来源已核实；血清学或无创筛查高风险的活产儿存在按实际出生日期计算至少84天的随访，儿童健康与来源不为未知。失访及拒访不会计为结案。妊娠结局按孕次共享，记录保留所登记项目和节点，不需在每个项目机械重复结局。

首页显示项目纳入数量、高风险/异常数量、待办和档案状态。尚未实现国家指标各分母纳入规则、周期筛选、样本质量、检出率/阳性预测值等完整统计；不应直接用于质控上报。上线后应由中心结合本院制度确认具体计划与资料核实要求。

## 导入、账号及升级

孕次页可下载 Excel 模板，导入 XLSX/XLS/CSV，最多 5 MB / 2000 行。支持工作表选择、字段匹配、预览、错误下载和重试去重。必填病案号、姓名、电话、孕次编号、胎数、项目；多个项目用逗号分隔。支持项目代码 serum、nipt、ultrasound、genetic、ultrasound_dx 或模板中的完整中文名称。

导入同一病案号但姓名/电话冲突时跳过并报错，须在基础档案人工核实。更新孕次保留空白资料原值，加入新项目，保留已有报告与随访记录。原通用患者、任务、记录和账号不迁移成推测的孕次，可在通用页面继续查看。

管理员与医护账号、密码修改、管理员重置/停用功能保持；产前资料仅登录后可访问。记录人由服务端绑定登录账号，报告修改、状态变更和计划调整均保留操作日志。孕妇端仅提供流程说明，文本/语音不读取患者档案或自动给医护发送消息。

数据库迁移：selfhost/init/06-prenatal.sql（可重复执行，新增独立表及关联字段）。生产部署前同时备份应用文件与 PostgreSQL；运行环境和语音配置保持原值。

验证入口：prenatal.test.cjs、prenatal.integration.cjs（仅限专用测试库）、prenatal.browser.cjs（仅限本地转发的测试服务）；并运行医院基础字段、账号和语音回归检查。
