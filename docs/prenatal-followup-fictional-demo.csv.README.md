# 虚构产前随访演示表

prenatal-followup-fictional-demo.csv 的全部行均独立构造，仅用于测试导入、字段映射和随访计划。姓名、病案号、孕次编号、医护与机构均为演示标识，不对应患者资料或截图记录。

日期留空，胎数包含单胎和双胎的格式样例，说明字段不包含真实检查日期、年龄或检验结果。示例项目名称来自系统支持的项目类型；项目选择不是诊断结论。

手机号使用 13900000001 至 13900000015 的格式样例，未经可达性核验，禁止拨打。DEMO- 病案在患者、任务、孕次与详情页面显示演示标识，并禁用电话链接；仅在隔离测试环境导入。

在仓库根目录运行 node docs/validate-prenatal-demo.cjs，验证导入格式和演示拨号保护；该脚本不访问服务端、不写数据库、不拨号。
